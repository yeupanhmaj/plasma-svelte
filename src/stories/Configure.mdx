# Plasma Svelte

> A faithful, modern **KDE Plasma 6 & Breeze** design system and component library built with **Svelte 5** and **TypeScript**.

---

## 🎨 Overview

**Plasma Svelte** brings the desktop elegance and clarity of KDE Plasma 6 and the Breeze design language to modern web applications. Built from the ground up for **Svelte 5**, it provides lightweight, accessible, and reactive UI controls.

## 🚀 Quick Start

### 1. Installation

```bash
# Using pnpm (recommended)
pnpm add plasma-svelte

# Using npm or yarn
npm install plasma-svelte
```

### 2. Import Styles

Include the global CSS design tokens and base styles in your root layout:

```svelte
<!-- src/routes/+layout.svelte -->
<script lang="ts">
  import "plasma-svelte/style.css"; // or $lib/style/index.css in development

  let { children } = $props();
</script>

{@render children()}
```

### 3. Using Components

```svelte
<script lang="ts">
  import {
    Button,
    Input,
    Checkbox,
    Radio,
    Switch,
    Slider,
    Card,
    Tabs,
    Badge,
    Tooltip
  } from "plasma-svelte";

  let search = $state("");
  let nightLight = $state(true);
  let volume = $state(70);
</script>

<!-- KDE Breeze Push Button -->
<Button variant="primary" onclick={() => alert("Action triggered!")}>
  Apply Settings
</Button>

<!-- Search Input with Clear Button -->
<Input placeholder="Search applications..." bind:value={search} clearable />

<!-- KDE Switch & Slider -->
<Switch bind:checked={nightLight} label="Night Light" />
<Slider bind:value={volume} label="Master Volume" showValue min={0} max={100} />
```

## 🌓 Theming & Color Modes

Plasma Svelte controls dynamically adapt to the active color palette.

### Switching Themes in Code
```html
<!-- Breeze Dark (Default) -->
<html data-theme="dark">

<!-- Breeze Light -->
<html data-theme="light">
```

### Switching in Storybook
Use the **Theme switcher** in the top toolbar to toggle between 🌙 **Breeze Dark** and ☀️ **Breeze Light** in real-time.
